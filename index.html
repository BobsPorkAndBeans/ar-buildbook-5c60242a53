Build Book · by Naber Research

Read-only tour. Everything here is fictional demo data: a made-up "Demo Race Shop," spec DEMO-90DEG-001, three engines, and a machining order from "Demo Machine Works." It's a snapshot of the app, so forms and Save buttons are switched off. Built phone-first, and it works on a laptop too.

Five-minute walk-through

  1. Start the guided tour

    The app opens with a short welcome and a seven-stop tour. Tap any ? for a plain-language hint.

  2. The spec

    One engine program: every part number and clearance band, written down once. Every engine is built to it.

  3. One engine, start to finish (build book)

    DEMO102-001 is filled in from A to Z with every check OK. Mic readings go in and each clearance is worked out for you, including the ring-gap tables per cylinder.

  4. Crank balance

    The same engine's balance work. Every piston, pin, ring set, rod end and bearing shell is weighed per cylinder, the bobweight is worked out with the formula shown and checked against the crank maker's number, and the balancer's card is typed in, with the sample printout attached. DEMO103-001 is still in progress, with a heavy piston and unweighed bearings flagged.

  5. The machine shop's side

    Machining order MO-DEMO-0001 from Demo Machine Works is linked both ways with the engine it was done for, so you can see what was asked for and what was achieved.

  6. The printed build report

    The same engine as a clean report, also in machine-shop and build-shop versions, and as a PDF.

  7. Spec revisions

    Cam bearing #3 went on back-order, so rev 2 approved a substitute. Rev 1 stays frozen and the diff shows exactly what changed.

  8. Containment

    A bought-in part has a quality problem? One search shows which engines got it.
