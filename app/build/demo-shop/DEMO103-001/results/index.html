Welcome to the Build Book

This is a working demo of the Build Book from Assembly Required by Naber Research.

What it's for: an engine gets built the same way every time, and every number gets written down. You write the plan once (the spec). Each engine on the stand gets its own record (the build), and the app checks each reading against the plan as it goes in.

Everything here is made up. “Demo Race Shop” and engines DEMO101, DEMO102 and DEMO103 aren't real, and nothing you click can change or break anything.

Demo only. The parts, clearances and checks shown are examples. Real setups are built around your engine and your shop.

Know engines? Quick reference

  • Clearance is computed per position from bore, insert and journal readings and graded against the spec band. Out-of-band readings are kept and flagged, never dropped (DEMO103-001 → rod bearing #7).
  • Machining orders: the block work order (MO-DEMO-0001) holds the shop's as-returned bore grid, Rpk / Rk / Rvk, crosshatch, hone temperature and the achieved deck, main-line, cam-tunnel and lifter-bore sizes. DEMO102-001 links to it; those values are carried into the build (marked “from MO-DEMO-0001”), main housing bores feed the main-bearing clearances, and the report lists the source.
  • Specs are revisioned: released revs are frozen, and the diff (Spec diff — rev 1 → rev 2) is computed from the frozen copies. A build records which rev it was built to.
  • Approved alternates per PN. Containment finds which engines got a primary or an alternate PN.
  • Units: each spec sets a system (this demo is Metric) with per-field overrides. Reports switch between display units and SI (or inch).
  • Report scopes: Engineering / Build shop / Machine shop, each as HTML, PDF and CSV.
  • Ring fit: back clearance is radial, graded on the ring-maker band when a land diameter is entered, otherwise on the installed band, otherwise shown ungraded. See DEMO103-001 → “Top ring fit” (cylinders 1–4 on the ring-maker band, 5–8 on the installed band).
  • Results: peaks are compared only within one correction standard (SAE J1349, STP and so on), never ranked across standards.
  • Everything is customized per application: the template, sections, line items and bands shown here are one example setup.
